# Velocity measurements — 2026-09-01

Measured on the Windows dev box (Rust 1.97.1 stable-msvc, pnpm 11.17.0, Node 24). Recorded here
because these numbers are the justification for the process rules now written into `CLAUDE.md`
(velocity mode, targeted intermediate gates, batching subagent spawns). Referenced from `TODO.md`.

## Gate wall-clock

- Full `pnpm gate`: **≈5–7 min**.
- `cargo nextest run --workspace`: **3m22** total, of which **141.8s** is test execution; **2051 tests**.
- `pnpm test` (vitest): **67.6s**, **199 files**, **2397 tests**.
- Playwright e2e: **unmeasured** in this pass.

## Rust: the parallelism floor

- Slowest single Rust test: `prop_graph_layout::graph_invariants_and_determinism` at **57s**.
- That is **~40% of Rust test wall time** on its own.
- It is the parallelism floor: nextest splits work **per test function**, so no amount of
  concurrency shortens it.

## vitest: jsdom construction dominates

- CPU-aggregate breakdown: `environment` **613s** vs `tests` **147s**.
- Cause: jsdom construction across **199 files**, not test bodies.
- Candidate fix: **happy-dom**, or `environmentMatchGlobs` to give jsdom only to the files that need
  it. **NOT yet done — candidate only, nothing implemented.**

## Rust inner loop is cheaper than assumed

- A `bonsai-core` edit that does **not** change exported metadata rebuilds only **4 units in 23s**.
- The **78 integration-test binaries do NOT relink** on such an inner-loop edit.
- They do relink on signature-changing edits and on cold/CI builds.

## Temp-directory fix (applied)

- Agent shells had been running with `TMP=TEMP=C:\Temp`, which is Defender-scanned (see the USER
  MANDATE in `TODO.md`).
- Now redirected to `D:\Data\Temp\bonsai-build` for gate child processes in `scripts/gate.mjs`.

## Where per-task wall clock actually goes

- Of the last 200 commits: **61 `docs:` bookkeeping** vs **24 `feat`** + **27 `fix`**.
- Small tasks (P92 / P93 / P95) took **1h45–2h45 wall clock** each.
- Conclusion: **orchestration ceremony — not machine time — is ~75–85% of per-task wall clock.**

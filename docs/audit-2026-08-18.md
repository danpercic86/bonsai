## §2 Confirmed bugs

### 2.1 Watcher test now fails RELIABLY under full-workspace load
`src-tauri/src/watcher.rs:247` — `git_internals_filtered` received a callback inside its
1.5 s "no callback" window in **both** full-workspace runs today (2/2), while passing 5/5
in serial isolation. This is the documented lazy-ReadDirectoryChangesW-flush class (drain
window already widened 700 ms → 1.5 s → 2.5 s per watcher.rs:178-183), but the suite has
grown enough (T1–T6 roughly doubled the workspace) that the stale-flush burst now
reliably outlives the drain — this is no longer an occasional flake; full local suite
runs are effectively red on this machine. Compounding it, the lib suite runs first, so
with default fail-fast one failure hides the other ~1500 tests.
**Fix suggestions:** make `watch_into_channel` drain until a *sustained* quiet period
measured after the last received event (loop until 2.5 s of continuous silence, with a
hard ceiling), and/or write a sentinel file after arming and wait for its callback before
declaring the watcher drained (positive synchronization instead of a timer). Consider
`--no-fail-fast` in CI's cargo-test step so one flake never masks the rest.

### 2.2 MUST-FIX — mid-stream `selectedIndex` out of range crashes the right panel
`src/components/WorkspaceRightPanel.tsx:265-267` renders `<CommitPanel node={graph.nodes[selectedIndex]}>`
gated only on `selectedIndex !== null && graph !== null`. During a streaming refetch
(`RepoWorkspace.tsx:973-1021`), `setGraph` publishes the first partial batch (512 rows) at
line 1000 **before** the selection remap at 1005 — so a selection at row ≥ 512 renders
`CommitPanel` with `node === undefined`, which dereferences `node.summary` at
`CommitPanel.tsx:134` → TypeError → ErrorBoundary takes down the workspace. Trigger is
routine: select a deep commit, then any watcher tick / manual refresh / focus rescan
restarts the stream. If the selected commit was rebased/GC'd away the crash persists to
stream end. The commit-diff *effect* guards exactly this case (`RepoWorkspace.tsx:1220-1224`
uses `?.` and skips) — the *render* path does not. Same hole at `WorkspaceRightPanel.tsx:281`
(`onExplain` does `graph.nodes[selectedIndex].id`).
**Fix:** render the CommitPanel branch only when `graph.nodes[selectedIndex] !== undefined`
(fall back to the status panel or a skeleton until the row arrives or the stream ends).

## §3 SHOULD-FIX

### Rust core
1. **Worktree-copy symlink write-through** — `crates/bonsai-core/src/git/worktree_copy.rs:232-245`.
   Containment is lexical only (`is_unsafe_rel` + `ensure_contained` = un-canonicalized
   `starts_with`). The copy runs after the target branch is checked out into the new
   worktree, so a branch whose tree contains a symlink (as the leaf or a directory
   component of `sel.path`) makes `fs::write(&dest, …)` follow it and write **outside**
   the worktree (e.g. symlink `config → ~/.gitconfig`, user picks Overwrite → `~/.gitconfig`
   clobbered; Unix, or Windows with symlink privilege). Fix: `symlink_metadata` check on
   `dest` + canonicalize `dest.parent()` against `wt_root` before writing (the same
   treatment `submodule.rs::remove_cached_git_dir` got in 3be010f).
2. **F-T5-4 (truncated-loose-object zlib spin) blast radius grew** — the documented hang
   (docs/testing-campaign-2026-08/FINDINGS.md) now also reaches (a) `stream_graph_core`
   (`graph/stream.rs` → `LaneWalker::step` → `find_commit`, lane.rs:120): the channel never
   sends `Done` and the frontend waits forever on a partial graph; (b) the background
   history indexer (`history_index/mod.rs` skip-and-count catches `Err`, but a truncated
   object *hangs*, wedging the indexer thread permanently). Nothing made the hang worse,
   but each release adds inflate surfaces while the recommended command-layer timeout
   remains unimplemented. Recommend closing this open decision now.
3. **Hook/indexer failures invisible in the UI** — `crates/bonsai-core/src/git/hooks.rs:194`
   maps a spawn failure to `ran:false` with empty output — indistinguishable from "no hook
   installed"; `history_index` reports skipped commits via `eprintln!` only. A post-commit
   hook that silently stopped running, or an index silently skipping commits, gives the
   user no signal. Plumb a warning field through the existing result types.

### App layer (src-tauri)
4. **Blocking `fs::canonicalize` under the `AppState.repos` mutex on the async runtime** —
   `src-tauri/src/commands/repo.rs:224-235`: the open-repo dedupe scan calls
   `same_repo_path` (two canonicalize calls) per open tab while holding the map lock,
   between the two `spawn_blocking` sections. A hung network volume blocks for the OS
   timeout while every concurrent command stalls in `repo_path`. Snapshot keys out of the
   lock and compare inside `spawn_blocking`.
5. **`registration_tests.rs` skip filter didn't follow the tests.rs split** —
   `src-tauri/src/commands/registration_tests.rs:88-91` skips `stem == "tests" || ends_with("_tests")`,
   but the 17 new test files are named `tests_*` and are scanned (a fixture string with a
   line-leading `#[tauri::command]` would break the bijection test), while a future real
   module named `*_tests.rs` would be silently excluded. Add `starts_with("tests_")`.
   (The bijection itself holds today: 160 = 160, hand-verified.)

### Forge + AI
6. **Forge HTTP transport hardening** — `crates/bonsai-forge/src/http.rs:105-109,135-137`:
   default reqwest client follows redirects (10 hops; reqwest strips Authorization only on
   cross-host redirects — a same-host `https→http` redirect re-sends the Bearer token in
   cleartext), and `resp.text()` reads the body unbounded. None of the four forge APIs
   legitimately redirect: set `redirect(Policy::none())` and cap the body read.
7. **AI child pid-reuse kill window** — `crates/bonsai-core/src/ai/session.rs:136` stores
   the child pid into the shared `Arc<AtomicU32>`; `reap()`/`complete()` kill+wait but never
   reset it to 0. Between sequential bulk batches, or between child exit and FinishGuard
   drop, `AiRunRegistry::cancel_all` (registry.rs:147, app-exit hook) can `taskkill /T /F`
   a pid the OS already recycled — killing an unrelated process tree. Fix: store 0 in
   `reap()` and `complete()`.

### Frontend
8. **streamAssembler throw escapes the Channel callback** — `src/graph/streamAssembler.ts:78-81`
   throws on a non-contiguous `startRow` from inside `Channel.onmessage`
   (`tauri.ts:182-188` via `RepoWorkspace.tsx:990`). In real Tauri that is an unhandled
   event-handler exception: `setGraphError` never fires, every later batch re-throws, the
   stream silently freezes while `graphLoading` clears as if it succeeded. (The mock calls
   the callback synchronously, so tests cannot see the divergence.) Wrap the `onChunk` body
   in try/catch → `setGraphError` + poison the stream so later chunks are dropped.
9. **`BulkAiConfirmDialog` missing from `dialogOpen`** — the disjunction at
   `src/components/RepoWorkspace.tsx:444-479` includes every other pending confirm but not
   `aiBulk.confirm.open`. Esc works, but workspace shortcuts stay live under the modal:
   Ctrl+K/Ctrl+F/F5 and graph navigation all act behind it. Add it to the list.
10. **Live AI runs are not cancelled on workspace unmount / tab close** —
    `src/components/repoWorkspace/useAiRuns.ts:226-232` cleanup only clears the flush timer
    and mounted latch. Closing a tab mid-run leaves the Claude CLI process running (and
    spending) with no dock or cancel affordance, and `settle` can still stage into a repo
    whose tab was just closed. Fire `aiCancelRun` for every non-terminal run in the unmount
    cleanup and skip `settle` staging when unmounted.

## §6 Checked and clean (redundant verifications that found nothing)

- **Forge token routing (the #1 adversarial question):** API bases are compile-time
  constants per provider; provider detection requires an exact SaaS-host match after
  userinfo/port strip; `https://github.com@evil.com/x` → host `evil.com` → Unknown;
  `require_supported()` precedes every HTTP call — a crafted remote cannot route a PAT to
  an attacker host.
- **Token storage:** OS keychain only, never in settings.json/URLs/IPC payloads; Debug
  redaction covers Authorization and `*token*` headers (incl. GitLab `PRIVATE-TOKEN`),
  with tests; `forge_set_token` returns only the viewer identity.
- **IPC parity:** IpcApi 168 = tauri.ts 168 = mock 168 (compile-enforced); 160 registered
  commands = 160 defined (self-tested); the 8-method delta reconciles exactly (4 event
  subscriptions, pickFolder, 3 updater-plugin methods) + 2 renamed mappings. TODO.md's
  "160" is accurate.
- **Force-checkout clobber guard:** every force checkout traced is guarded by
  `ensure_no_untracked_collision` (bisect ×2, rebase_interactive ×3, rebase ×1) or
  deliberately path-scoped with an empty-set guard (merge abort, stash mutate window).
- **CRLF/check-in filters:** all 58 `fs::read` sites audited — no recurrence of the
  raw-read-into-blob class fixed in the last audit; stash staged-delete fold uses
  filter-aware `blob_path`.
- **Hooks:** exec-style argv (no shell), `--ignore-missing` always present, no BatBadBut
  exposure (`Command::new("git")`, Rust ≥1.58 no-CWD search), 64 MiB output cap,
  never-prompt env hygiene.
- **AI containment:** repo content is stdin-only; argv is constants + single-line prompts
  (asserted by test); `--permission-mode manual` unconditional; planner is a closed
  allowlist with `deny_unknown_fields` failing closed; the only write path is
  `resolve_conflict_text` behind `validate_rel_path`; bulk attribution exact-match with
  markerful bodies failed, not proposed; every `ai_*` command consent-gated (dedicated
  test file).
- **AI process lifecycle:** concurrency cap check-and-insert under one lock; FinishGuard
  removes entries on every exit incl. panic; app-exit `cancel_all` wired; cancel latency
  bounded at 250 ms even with a stdin-wedged child (modulo §3.7 pid-reuse).
- **Streaming graph:** one-shot and streaming paths share one `LaneWalker` and one seeded
  revwalk (`TOPOLOGICAL | TIME`) — lane stability across chunks holds by construction;
  channel-drop cancels the walk promptly; frontend stale-stream gating via `graphReqId`
  precedes chunk application; spacer never shrinks below loaded rows.
- **Locks:** no sync mutex held across await anywhere; poison recovery standardized;
  settings writes all serialize through `SETTINGS_IO` + `settings::update` (including the
  new P67/P68 fields); MCP start-guard + ephemeral-port token rotation intact.
- **Watcher (app):** debounce/shutdown/canonicalized-root all verified again.
- **Contract conformance:** P62/P63/P64/P65/P67/P68 acceptance criteria spot-checked
  against shipped code — all met except the honestly-reframed P65 first-paint (§5.5);
  contracts INDEX.md fully current.

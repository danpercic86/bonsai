## Recommended follow-ups (NOT done here — need your decision or a larger effort)

**Security / correctness (your call):**
- **AI novel-content gate (P68 #7)** — under `aiConflictAutonomy: autoResolve`, a hostile
  "theirs" side can instruct the conflict model to embed repo secrets into a marker-free
  merged file. The structural fix (exclude proposal lines present in none of
  base/ours/theirs) has real false-positive risk (legit resolutions produce novel lines),
  which is why it's deferred. Default is the safer `proposeReview`. **Decide** whether to
  implement the gate or keep the current posture.
- **Git-hook execution disclosure** — hooks run by default when you commit/merge a
  pre-existing on-disk repo (git parity; clone never transfers hooks). Consider a
  one-time per-repo disclosure.
- **Credential error scrubbing** (`cred.rs`) — an HTTPS remote URL with inline
  `user:password@host` could echo the secret into an error toast. Cheap to scrub.
- **Conflict-write leaf symlink** — the symlink guard blocks ancestor escapes; a leaf
  that is itself a symlink is still followed by `fs::write` (heavily constrained by
  requiring a live index conflict at that path). Optional hardening.

**UI/UX (designer-recommended):**
- **Icon system (epic)** — the app uses raw Unicode/emoji glyphs as icons
  (`☀ ☰ ⚙ 🤖 📊 ↶ ↓ ⇣ ↑ ⎇ …`); the designer's verdict is to standardize on the existing
  inline-SVG idiom (`menuIcons.tsx`) via a new `appIcons.tsx`, color-emoji first. A
  multi-increment migration — recommended but too large to do unattended. Plan is in
  `docs/contracts/review-2026-08-22-ui.md` §C.
- **Sidebar polish** — initial keyboard focus lands on the Branches header rather than
  the HEAD branch (async-load nit); type-ahead is deferred per the contract; the sidebar
  ignores `panelDensity`.

**Backend nits:** the `notify` watcher doesn't watch a linked worktree's refs (relies on
manual/focus refresh); a few low-value untested modules (`error.rs`, `git/mod.rs`,
`state.rs`); a couple of MED UI test gaps (UpdateDialog, ComposerDialog, ComparePanel,
FileHistoryView/BlameView). Full list in the review's working notes.
